## プロジェクト構成

外部ライブラリ、依存パッケージ、ビルド処理を使わない静的HTMLサイトです。`dist/index.html`をブラウザで開くか、`dist/`を静的配信します。

`content.js`、`lesson8.js`、`resources.js`、`app.js`の順に`defer`で読み込みます。`lesson8.js`は第8回のデータに加え、第1〜7回のカードへ相互リンクを追加するため、必ず含めてください。

`.openai/hosting.json`は従来のSites設定をそのまま同梱しています。別のホスティングを利用している場合、その既存設定を優先してください。`.git`、認証情報、元PPTX、原本書き起こしは同梱していません。
