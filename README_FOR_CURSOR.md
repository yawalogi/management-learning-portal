# Cursorへの作業指示

このフォルダは「やわらかロジカルシンキング 学習ポータル」の完成版です。
表示内容・デザインは確定済みです。GitHubへの登録に必要な作業だけを行い、サイトの文章、画像、レイアウト、リンク、ファイル名は変更しないでください。

## プロジェクト構成

- `dist/index.html`：入口ページ
- `dist/style.css`：表示デザイン
- `dist/app.js`：画面生成と操作
- `dist/content.js`：講義コンテンツ
- `dist/resources.js`：動画・資料リンク
- `dist/assets/`：ヘッダー画像
- `dist/slides/`：4:3、1200×900のスライド画像21枚
- `.openai/hosting.json`：現在のホスティング設定。認証情報は含まれていません

外部ライブラリやビルド処理を使わない、静的なHTMLサイトです。

## 依頼内容

1. このフォルダをGitリポジトリとして準備してください。
2. GitHubの登録先リポジトリがCursorの会話内で指定されていなければ、作成・Pushの前に、次の3点をユーザーへ確認してください。
   - リポジトリ名
   - 新規作成か、既存リポジトリへの追加か
   - 公開か非公開か
3. 動画とGoogle Driveの資料リンクが含まれるため、公開範囲の指定がなければ非公開リポジトリを推奨してください。
4. `.git` フォルダは同梱されていません。新規リポジトリの場合は、このフォルダをルートとして初期化してください。
5. すべてのファイルを確認し、認証情報や一時ファイルがないことを確かめてください。
6. 次の確認を行ってください。
   - `node --check dist/app.js`
   - `node --check dist/content.js`
   - `node --check dist/resources.js`
   - `dist/slides/` にPNGが21枚あること
   - 各スライド画像が1200×900であること
7. 最初のコミットメッセージは `Add management learning portal` としてください。
8. 指定されたGitHubリポジトリの `main` ブランチへPushしてください。
9. 完了後、GitHubリポジトリのURL、ブランチ名、コミットSHAをユーザーへ報告してください。

## 変更しないもの

- サイトの文章と講義内容
- ヘッダーとスライド画像
- YouTube、Google Drive、申込ページへのリンク
- 4:3のサムネイル表示
- 1ページ構成とナビゲーション
- URL末尾のキャッシュ更新用パラメータ

GitHub Pagesなどへの公開設定は、ユーザーから明示的に依頼された場合だけ行ってください。
